# 小海智家

把「小海智家」账号下的空调、地暖和新风接到 Home Assistant。设备列表、状态和控制都走小海私有云，不使用涂鸦公有云，也不连接家里的网关。

## 功能

- 手机号或邮箱登录
- 每 30 秒从云端刷新状态。重新加载集成时会重新拉取设备列表
- 空调：开关、模式、目标温度、风速、当前温度
- 地暖：开关、目标温度、当前温度
- 新风：开关和风速
- 每台设备一个连接状态。云端房间名会填进 Home Assistant 里还没分配区域的设备

新风没有温度。读数为 0°C 时不显示。

## 安装

1. HACS → 集成 → 右上角菜单 → 自定义存储库。
2. 仓库填 `https://github.com/wenwenba/xiaohai-homeassistant`，类别选 **Integration**。
3. 下载「小海智家」，重启 Home Assistant。
4. 设置 → 设备与服务 → 添加集成 → 小海智家。

## 配置

| 字段 | 说明 |
| --- | --- |
| 手机号或邮箱 | 小海智家 App 的登录账号 |
| 密码 | App 密码。只保存在 Home Assistant 的配置项里 |
| 国家码 | 默认 `86` |

不要把密码写进这个仓库或聊天记录。

## 说明

控制通过云端下发到网关，再由网关转给子设备。网关也会出现在设备列表里，通常只有连接状态。云端没有房间归属时，区域留空，可在 Home Assistant 里手动指定。
